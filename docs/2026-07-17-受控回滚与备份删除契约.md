# 受控回滚与备份删除契约

## 备份路径

删除和回滚前必须将备份路径解析为绝对路径，并确认其位于 NAPM_UPGRADE_BACKUP_ROOT 的子目录中。拒绝根目录本身和任何越界路径。备份路径不在服务响应中返回。

## 人工回滚

当前人工回滚仅支持 Skill 组件。升级服务创建可跟踪的回滚任务 ID，任务使用现有的合法 Skill 任务类型写入 upgrade_tasks，从而避免旧实现中 rollback 类型与数据库约束冲突。

核心和前端组件的人工回滚未开放：它们需要各自的重载、健康检查和失败恢复编排，不能复用 Skill 的通用 smokeTest。

## 删除

按备份记录 ID 删除。物理目录删除成功后才删除记录，并保留不包含备份路径的审计摘要。
