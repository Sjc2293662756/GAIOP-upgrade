# 升级包受控暂存与 BFF 操作契约

## 上传链路

浏览器到 Admin BFF，再到升级服务。两侧都使用受控磁盘暂存目录，最大包大小为 500MB；普通 ZIP 由升级服务从暂存文件路径校验，校验通过后才复制到任务包目录，校验失败或请求结束后清理暂存文件。

升级服务不向浏览器开放。BFF 使用内部令牌和派生的管理员操作者调用 validate 与 execute。

## 执行边界

升级服务只接受已校验且处于 pending 状态的 task_id。Admin BFF 要求管理员输入 EXECUTE 作为二次确认，且不转发浏览器提交的 force、操作者或服务器路径。BFF 与升级服务分别留下审计记录。

## 已知限制

普通 ZIP 上传不再被 multer memoryStorage 整包保留在内存。现有加密包解密逻辑仍会在解密阶段读取完整内容，这是加密包的遗留实现限制；ISO 发布前应继续改造成文件流解密后再交给校验器。
