# GAIOP 升级留存资格核查实现

第十二批新增 `src/services/RetentionQualification.js`，只读判定升级包、staging 和组件回滚备份是否达到第一批低风险清理资格。模块不调用 `PackageCleaner`、`BackupCleaner` 或删除 API，不创建锁/审计，不执行数据库迁移；数据库调用方必须提供 `readonly`、`query_only` 连接。

升级包按严格 UUID v4 文件名和 `upgrade_tasks` 归属判断：活动任务、未知归属、异常时间和非终态全部保护；`failed`/`rolled_back` 必须同时严格超过 7 天。staging 必须由调用方提供无任务、无锁、无活动引用证明，缺少证明时为 `unknown_or_error`。回滚备份必须有数据库归属、严格超过 90 天、超出每组件最近 5 个可用组、非共享物理目录、有效 manifest 和完整文件结构；数据库无归属目录不扫描。

输出只包含策略版本、类别、计数、字节数、UTC 时间和稳定原因码，不返回完整路径、任务标识或业务内容。该实现分支没有部署 237，也没有读取、删除或修改生产升级包、staging、回滚备份或数据库。
