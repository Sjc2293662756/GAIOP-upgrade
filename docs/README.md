## 永久边界

- 浏览器只访问 GAIOP Admin BFF，不直连18900。
- `/health` 以外的升级服务接口必须同时验证内部Token和操作者身份。
- 生产配置、Token、签名私钥、上传包、数据库和备份不得进入Git。
- OpenClaw核心和频道插件升级仍需兼容矩阵、全插件/全频道验证和失败整体回滚；现有基础能力不等于已经完成真实业务升级验收。
